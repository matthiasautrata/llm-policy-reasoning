# DDL: LinkML (gen-sqlddl, postgresql) vs shared/gen.py

Generated by `build.py`. Column names, order and types agree in both passes (VARCHAR/TEXT are the same type in Postgres and DuckDB); `"limit"` is quoted by both. Neither pass emits gen.py's three secondary indexes (emp_cc, req_requester, cc_parent): LinkML has no index construct. Both generated files load into Postgres 18 (`psql -f`, checked by hand on 2026-11-24).
